# 📩 Telegram Spam Detection
A telegram spam message clasifier build on top of NLP




## 🛠 Prerequisites
Ensure you have the following installed:

- **Python** (v3.11 or higher)
    
## Run Locally

Clone the project

```bash
  git clone https://github.com/blablablacksheep11/Data-Mining-NLP
```

Install dependencies

```bash
  pip isntall -r requirements.txt
```

**Streamlit terminal**
```bash
  streamlit run app.py
```
## Deployment

The project is also accessible through the following URL:
